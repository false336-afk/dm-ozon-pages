DM Ozon Reporter

Частный инструмент для ежедневной отчётности по продажам на Ozon

DM Ozon Reporter — небольшое приложение, которое ежедневно формирует отчёт по продажам на маркетплейсе Ozon и автоматически рассылает его по электронной почте владельцу магазина и его коллегам.

Приложение предназначено для частного использования и не является публичным сервисом.

Политика приватности

Приложение: DM Ozon Reporter

Какой доступ используется

Приложение использует доступ Gmail с областью действия gmail.send исключительно для отправки писем с отчётами о продажах на Ozon. Этот доступ позволяет только отправлять письма от имени пользователя и не даёт возможности читать входящую почту, папки или переписку.

Какие данные обрабатываются

Приложение обрабатывает данные о продажах, полученные из личного аккаунта Ozon владельца, и использует их только для формирования ежедневного отчёта. Приложение не читает почту пользователя, не собирает и не передаёт данные третьих лиц.

Хранение и передача данных

Данные используются исключительно для формирования и отправки отчётов внутри приложения. Данные не продаются, не передаются и не используются в рекламных или иных целях, не связанных с формированием отчётов.

Кто использует приложение

Приложение является частным инструментом и предназначено для использования владельцем и его коллегами.
